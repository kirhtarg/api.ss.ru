# Настройки PHP для загрузки больших видео файлов

Для корректной работы загрузки видео файлов размером до 100MB необходимо настроить следующие параметры в файле `php.ini`:

## Обязательные настройки

```ini
; Максимальный размер загружаемого файла
upload_max_filesize = 100M

; Максимальный размер POST данных
post_max_size = 100M

; Максимальное время выполнения скрипта (в секундах)
max_execution_time = 300

; Максимальное время загрузки файла (в секундах)
max_input_time = 300

; Лимит памяти для PHP скриптов
memory_limit = 256M
```

## Дополнительные настройки (рекомендуемые)

```ini
; Максимальное количество файлов для загрузки
max_file_uploads = 20

; Включение загрузки файлов
file_uploads = On

; Временная папка для загрузки (по умолчанию системная)
; upload_tmp_dir = /tmp
```

## Как найти файл php.ini

### Windows (XAMPP/WAMP)
- Обычно находится в `C:\xampp\php\php.ini` или `C:\wamp\bin\php\php.ini`
- Или выполните команду: `php --ini`

### Linux (Ubuntu/Debian)
- Обычно находится в `/etc/php/8.x/apache2/php.ini` или `/etc/php/8.x/fpm/php.ini`
- Или выполните команду: `php --ini`

### macOS (MAMP)
- Обычно находится в `/Applications/MAMP/bin/php/php8.x.x/conf/php.ini`

## После изменения настроек

1. **Перезапустите веб-сервер** (Apache/Nginx)
2. **Перезапустите PHP-FPM** (если используется)
3. Проверьте настройки командой: `php -i | grep -E "(upload_max_filesize|post_max_size|max_execution_time|memory_limit)"`

## Проверка текущих настроек

Выполните команду для проверки текущих настроек:
```bash
php -i | grep -E "(upload_max_filesize|post_max_size|max_execution_time|memory_limit)"
```

## Альтернативные решения

Если настройка PHP невозможна, рассмотрите:
1. Сжатие видео перед загрузкой
2. Использование внешних сервисов хранения (AWS S3, Google Cloud Storage)
3. Загрузка через FTP/SFTP
4. Разбиение больших файлов на части
