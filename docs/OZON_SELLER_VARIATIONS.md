# Ozon Seller: категории и вариации

## Подготовка

1. Создайте в справочнике магазина тег `Ozon`.
2. В разделе Ozon Seller выберите этот тег в поле `Тег товаров Ozon`.
3. Назначайте тег только товарам, данные которых готовы к публикации.
4. Укажите `Warehouse ID`, если остатки передаются по FBS или rFBS.

В синхронизацию попадают только активные товары, которые одновременно имеют выбранный тег и входят хотя бы в один активный профиль категорий.

## Профиль категории

Профиль связывает одну или несколько категорий магазина с одной парой `description_category_id / type_id` Ozon. В дереве магазина можно выбрать одну категорию или всю ветвь вместе с подкатегориями.

Одна локальная категория не может одновременно входить в разные профили. Это исключает неоднозначный выбор категории и характеристик Ozon.

## Режимы вариаций

- `Объединять в карточку`: каждая активная вариация становится отдельным оффером, но получает общее название модели. Это основной режим для размеров и цветов.
- `Отдельные карточки`: каждая активная вариация становится независимой карточкой Ozon.
- `Один родительский оффер`: вариации не передаются отдельно. Используйте только для товаров без значимых продаваемых вариантов.

Для объединения выберите характеристику Ozon `Название модели` и сопоставьте оси вариаций, например `Размер -> Размер` и `Цвет -> Цвет товара`. Если характеристика Ozon словарная, загрузите её словарь и сопоставьте каждое локальное значение.

В общих характеристиках Ozon доступны источники: поле товара, характеристика товара, бренд, поле вариации и постоянное значение. Для словарной характеристики товара сначала выберите локальную характеристику, затем загрузите `Значения Ozon` и сопоставьте значения. Обязательное поле без значения блокирует отправку.

## Идентификаторы

Новый оффер получает стабильный технический идентификатор:

- товар без вариаций: `g_{good_id}`;
- вариация: `g_{good_id}_v_{variation_id}`.

Артикул можно менять без создания дубля. Для уже синхронизированных карточек сохраняется прежний `offer_id` из таблицы привязок.

## Проверка

Перед первой отправкой укажите ID тестовых товаров и нажмите `Проверить товары`. В таблице должна появиться отдельная строка для каждого будущего оффера. Отправка карточки блокируется при отсутствии цены, изображения, габаритов, обязательной характеристики, словарного соответствия или при повторении комбинации вариаций.

## Синхронизация

- `Карточки` отправляет полное описание, изображения, габариты и характеристики.
- `Цены` обновляет цену каждого оффера отдельно.
- `Остатки` обновляет остаток каждой вариации на выбранном складе.

Отключённые вариации не удаляются из Ozon автоматически. В блоке `Карточки на Ozon` они отмечаются отдельно; кнопка `Обнулить остаток` безопасно прекращает их продажу. Решение об архивировании принимается вручную.

Кнопка `Получить состояние Ozon` обновляет удалённые идентификаторы и статусы карточек. Журнал синхронизации хранит результат каждого запуска и ошибки отдельных офферов.
