# Инструкции по запуску миграции

## Добавление полей скидок в таблицу shop_orders

Для добавления полей скидок в таблицу заказов необходимо выполнить миграцию на удаленном сервере:

```bash
php artisan migrate
```

Эта команда выполнит миграцию `2025_01_20_000013_add_discount_fields_to_shop_orders.php`, которая добавит следующие поля:

### Новые поля в таблице shop_orders:

1. **Поля скидок:**
   - `sale_discount_amount` - Скидка по акционным ценам
   - `registered_user_discount_amount` - Скидка для зарегистрированных пользователей
   - `promo_code_discount_amount` - Скидка по промокоду
   - `total_discount_amount` - Общая сумма всех скидок

2. **Поля промокода:**
   - `promo_code` - Код промокода
   - `promo_code_id` - ID промокода

3. **Поля бонусов:**
   - `use_bonus_points` - Использованы ли бонусы
   - `bonus_points_to_use` - Количество списанных бонусов
   - `order_bonus_points` - Бонусы за заказ

4. **Стоимость доставки:**
   - `delivery_cost` - Стоимость доставки

### После выполнения миграции:

1. Все заказы будут записываться с детальной информацией о скидках
2. Каждый тип скидки будет храниться в отдельном поле
3. Информация о промокодах и бонусах будет сохраняться
4. Статус заказа будет браться из таблицы `shop_order_statuses`

### Проверка:

После выполнения миграции можно проверить структуру таблицы:

```sql
DESCRIBE shop_orders;
```

Все новые поля должны быть добавлены с правильными типами данных и значениями по умолчанию.
