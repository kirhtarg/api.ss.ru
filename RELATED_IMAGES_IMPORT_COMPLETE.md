# Функционал связанных изображений для импорта товаров

## Обзор

Реализован функционал для работы со связанными изображениями при импорте товаров. Теперь система может автоматически скачивать изображения по URL и сохранять их в связанной таблице `shop_good_images`.

## Новые возможности

### 1. UI компонента импорта

- **Переключатель "Связанное изображение"** - включает/выключает функционал связанных изображений
- **Виртуальное поле "Связанное изображение"** - при включении переключателя добавляется виртуальное поле в список полей для маппинга (можно сопоставить с несколькими полями из файла)
- **Действие с изображениями** - выбор стратегии обработки изображений:
  - **Добавлять к существующим** - новые изображения добавляются к уже имеющимся
  - **Заменять все существующие** - все старые изображения удаляются, добавляются новые
  - **Пропускать, если изображения есть** - если у товара уже есть изображения, новые не добавляются

### 2. Параметры компонента

```javascript
// Новые параметры для GoodsImport.vue
relatedImageTable: {
  type: String,
  default: 'shop_good_images'
},
relatedImageFields: {
  type: Object,
  default: () => ({
    file_path: 'file_path',
    alt_text: 'alt_text', 
    is_main: 'is_main',
    sort_order: 'sort_order'
  })
}
```

### 3. API endpoints

#### POST `/admin/shop/goods/{goodId}/images/import`

Создает связанное изображение для товара при импорте.

**Параметры:**
- `file_path` (string, required) - путь к скачанному файлу изображения
- `alt_text` (string, optional) - альтернативный текст изображения
- `is_main` (boolean, optional) - является ли изображение главным
- `sort_order` (integer, optional) - порядок сортировки
- `image_action` (string, optional) - действие с изображениями: 'add', 'replace', 'skip'

**Ответ:**
```json
{
  "success": true,
  "message": "Связанное изображение успешно создано",
  "data": {
    "id": 1,
    "good_id": 123,
    "image_path": "/images/shop/goods/hash.jpg",
    "alt_text": "Название товара",
    "is_main": true,
    "sort_order": 0
  }
}
```

## Логика работы

### 1. Обработка изображений

1. **Скачивание изображений** - система скачивает изображения по URL на бэкенд
2. **Оптимизация** - изображения автоматически оптимизируются (сжатие, изменение размера)
3. **Сохранение** - файлы сохраняются в папку `/images/shop/goods/` с хеш-именем
4. **Создание записи** - в таблице `shop_good_images` создается запись с путем к файлу

### 2. Стратегии обработки

- **add** - добавляет новые изображения к существующим
- **replace** - удаляет все существующие изображения товара, добавляет новые
- **skip** - пропускает добавление, если у товара уже есть изображения

### 3. Интеграция с импортом

- Связанные изображения обрабатываются после успешного импорта товаров
- Система получает `good_id` для каждого импортированного товара
- Изображения создаются только для успешно импортированных товаров

## Использование

### 1. В интерфейсе импорта

1. Загрузите файл с данными товаров
2. Включите переключатель "Связанное изображение" (добавится виртуальное поле)
3. На этапе маппинга сопоставьте виртуальное поле "Связанное изображение" с полями из файла, содержащими URL изображений (можно сопоставить с несколькими полями)
4. Выберите действие с изображениями
5. Запустите импорт

### 2. В коде

```vue
<GoodsImport
  :related-image-table="'shop_good_images'"
  :related-image-fields="{
    file_path: 'image_path',
    alt_text: 'alt_text',
    is_main: 'is_main', 
    sort_order: 'sort_order'
  }"
  :image-storage-path="'/images/shop/goods'"
/>
```

## Структура данных

### Таблица shop_good_images

- `id` - уникальный идентификатор
- `good_id` - ID товара (связь с shop_goods)
- `image_path` - путь к файлу изображения
- `alt_text` - альтернативный текст
- `is_main` - главное изображение
- `sort_order` - порядок сортировки

### Формат импортируемых данных

```csv
name,sku,price,image_url,image_url_2,image_url_3
"Товар 1","SKU001",1000,"https://example.com/image1.jpg","https://example.com/image1_2.jpg","https://example.com/image1_3.jpg"
"Товар 2","SKU002",2000,"https://example.com/image2.jpg","https://example.com/image2_2.jpg",""
```

**Примечание:** Можно сопоставить виртуальное поле "Связанное изображение" с несколькими полями из файла (например, image_url, image_url_2, image_url_3). Система обработает все непустые URL и создаст соответствующие записи в shop_good_images.

## Обработка ошибок

- Если изображение не удалось скачать - поле пропускается, ошибка записывается в статистику
- Если файл изображения не найден - возвращается ошибка 404
- Если товар не найден - изображение не создается
- Все ошибки логируются в консоль для отладки

## Статистика

В результатах импорта отображается:
- Общее количество обработанных изображений
- Количество успешно скачанных
- Количество ошибок
- Список URL, которые не удалось обработать

## Безопасность

- Валидация URL изображений
- Проверка форматов файлов (jpg, png, gif, webp, bmp, svg, tiff, ico)
- Ограничение размера файла (10MB)
- Генерация уникальных имен файлов через хеширование
- Проверка существования товара перед созданием изображения

## Производительность

- Изображения скачиваются параллельно
- Оптимизация изображений происходит на бэкенде
- Кэширование скачанных файлов по хешу URL
- Асинхронная обработка для неблокирующего UI
