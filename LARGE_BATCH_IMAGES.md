# Работа с большими пакетами изображений

## Проблема

При импорте большого количества товаров с изображениями может возникнуть ситуация, когда изображений больше, чем максимально допустимый размер пакета:

- **Загрузка изображений**: максимум 50 изображений за запрос
- **Создание записей**: максимум 100 записей за запрос

## Решение

Фронтенд автоматически разбивает большие массивы изображений на пакеты оптимального размера:

### Загрузка изображений
- **Размер пакета**: 50 изображений
- **Автоматическое разбиение**: если изображений больше 50, они разбиваются на пакеты
- **Пауза между пакетами**: 200мс для снижения нагрузки на сервер

### Создание записей изображений
- **Размер пакета**: 100 записей
- **Автоматическое разбиение**: если записей больше 100, они разбиваются на пакеты
- **Пауза между пакетами**: 100мс для снижения нагрузки на сервер

## Примеры работы

### 150 изображений для загрузки
```
Загрузка 150 изображений пакетами по 50
Загрузка пакета 1/3 (50 изображений)
Загрузка пакета 2/3 (50 изображений)
Загрузка пакета 3/3 (50 изображений)
Всего загружено изображений: 150/150
```

### 250 записей изображений для создания
```
Создание 250 изображений пакетами по 100
Обработка пакета 1/3 (100 изображений)
Обработка пакета 2/3 (100 изображений)
Обработка пакета 3/3 (50 изображений)
Всего создано изображений: 250/250
```

## Настройка размеров пакетов

Размеры пакетов можно изменить в коде:

### Фронтенд (GoodsImport.vue)
```javascript
// Загрузка изображений
const BATCH_SIZE = 50 // Максимальный размер пакета для загрузки

// Создание записей
const BATCH_SIZE = 100 // Максимальный размер пакета для создания
```

### Бэкенд (контроллеры)
```php
// ShopGoodsController.php
'imageUrls' => 'required|array|min:1|max:50', // Максимум 50 изображений

// ShopGoodImagesController.php
'images' => 'required|array|min:1|max:100', // Максимум 100 записей
```

## Производительность

### Ожидаемые результаты

| Количество изображений | Время загрузки | Время создания записей | Общее время |
|------------------------|----------------|------------------------|-------------|
| 50 | ~5-10 сек | ~2-3 сек | ~7-13 сек |
| 100 | ~10-20 сек | ~3-5 сек | ~13-25 сек |
| 200 | ~20-40 сек | ~5-10 сек | ~25-50 сек |
| 500 | ~50-100 сек | ~10-20 сек | ~60-120 сек |

*Время может варьироваться в зависимости от размера изображений и скорости интернета*

### Оптимизация

1. **Паузы между пакетами** - предотвращают перегрузку сервера
2. **Параллельная обработка** - изображения в пакете обрабатываются параллельно
3. **Группировка по настройкам** - изображения с одинаковыми настройками группируются
4. **Удаление дубликатов** - одинаковые URL загружаются только один раз

## Ограничения

### Серверные ограничения
- **Максимальный размер запроса**: зависит от настроек PHP/веб-сервера
- **Таймаут запроса**: 300 секунд для больших пакетов
- **Память**: может потребоваться увеличение `memory_limit`

### Рекомендации
- **Не более 1000 изображений** за один импорт
- **Разбивать на части** при импорте более 500 изображений
- **Мониторить логи** для выявления проблем
- **Тестировать на staging** перед продакшеном

## Устранение неполадок

### Ошибка таймаута
```
❌ HTTP ошибка: 504
```
**Решение**: Увеличить таймаут в настройках веб-сервера

### Ошибка памяти
```
❌ Исключение: Allowed memory size exhausted
```
**Решение**: Увеличить `memory_limit` в php.ini

### Ошибка размера запроса
```
❌ HTTP ошибка: 413
```
**Решение**: Увеличить `post_max_size` и `upload_max_filesize` в php.ini

### Медленная загрузка
**Решение**: 
- Уменьшить размер пакетов
- Увеличить паузы между пакетами
- Проверить скорость интернета
- Оптимизировать изображения на сервере
