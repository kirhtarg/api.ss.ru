# Partner API формировал товарные изображения на API-домене

**Date:** 2026-08-01 17:40
**Files:** app/Http/Resources/Partner/V1/CatalogImageResource.php, tests/Unit/Partner/PartnerCatalogResourcesTest.php
**Severity:** high

## Problem

Partner API возвращал ссылки вида `https://api.skateandsnow.ru/images/shop/goods/...`, которые не обслуживаются API-доменом и отображались в SportRep как битые изображения.

## Root Cause

`CatalogImageResource` преобразовывал относительный путь через Laravel helper `url()`. Он использует `APP_URL`, предназначенный для API, хотя товарные файлы размещены публичным storefront.

## Solution

Относительные товарные пути объединяются с `config('app.frontend_url')`, который управляется `FRONTEND_URL`. Абсолютные внешние URL остаются без изменений. Добавлен unit-тест ожидаемого storefront origin.

## Prevention

- Разделять origin API и origin публичных медиа в конфигурации.
- Не использовать `url()` для файлов, физически обслуживаемых другим приложением.
- Проверять абсолютные media URL в контрактных тестах Partner API.
