# Laravel API routes failed to parse after unresolved merge

**Date:** 2026-07-13 16:40
**Files:** routes/api.php
**Severity:** critical

## Problem

All public API endpoints, including `/api/public/site-info`, returned HTTP 500
with `syntax error, unexpected token "<<", expecting end of file`.

## Root Cause

An unresolved Git merge marker block was committed at the end of
`routes/api.php`. Laravel loads this file while bootstrapping every API request,
so the PHP parse error prevented all routes from being registered.

## Solution

Removed the orphaned `<<<<<<<`, `=======`, and `>>>>>>>` lines and verified the
route file with `php -l` and `php artisan route:list --path=public/site-info`.

## Prevention

- Reject conflict markers in CI and pre-deployment checks.
- Run `php -l routes/api.php` and Laravel route discovery before deployment.
- Add an HTTP smoke test for `/api/public/site-info`.
