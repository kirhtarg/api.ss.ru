# Административная выдача недоступных товаров Partner API

**Date:** 2026-08-02 13:00
**Files:** app/Http/Controllers/Api/Partner/V1/CatalogController.php, app/Services/Partner/PartnerCatalogService.php, resources/openapi/partner-v1.json, docs/PARTNER_API.md, tests/Feature/PartnerApi/PartnerCatalogV11HttpTest.php
**Severity:** high

## Problem

Административная таблица SportRep получала ноль товаров, когда в магазине не было позиций с локально резервируемым остатком, хотя товары, вариации и информационные удаленные остатки существовали.

## Root Cause

Обычная выдача Partner API намеренно исключала недоступные для checkout товары. Тот же режим использовался административным каталогом, которому нужен полный перечень активных отображаемых позиций.

## Solution

Добавлен документированный boolean-параметр `include_unavailable`. При его включении выдаются все активные отображаемые товары, но фактические флаги доступности и ограничения checkout не изменяются. Обычный каталог без параметра сохраняет прежнюю фильтрацию. Добавлено журналирование `[FIX:partner-admin-catalog]` и HTTP-тест.

## Prevention

Разделять витринную доступность и административную видимость каталога явным параметром контракта. Любое расширение Partner API отражать в OpenAPI, документации и HTTP-тестах.
